# AI Engineer Path

This repository documents my hands-on learning journey from **Data Analytics and Business Intelligence toward AI Engineering**.

My goal is to build strong foundations in programming, machine learning, and software engineering while applying each concept through practical exercises and real-world projects.

Rather than focusing only on theory, this repository follows a **learning-by-building approach**: each stage introduces new concepts that are progressively incorporated into more complete projects.

## Background

I currently work in Data Analytics and Business Intelligence, with experience using tools and technologies such as:

* SQL
* Python
* Tableau
* Power BI
* Snowflake
* PySpark
* Airflow
* Sigma Computing

This background provides a strong foundation in data analysis, data transformation, business logic, and visualization.

The purpose of this repository is to expand those skills toward building **AI-powered applications and production-ready machine learning systems**.

## Learning Roadmap

The learning path is organized into progressive stages:

1. Python Fundamentals
2. Python Engineering
3. Data Structures and Algorithms
4. Machine Learning Foundations
5. Machine Learning Engineering
6. Deep Learning
7. LLM Engineering and RAG
8. AI Agents
9. MLOps and Deployment

The roadmap may evolve as new concepts, tools, and projects are introduced.

## Learning Approach

Each stage follows a practical workflow:

**Concept → Exercise → Implementation → Review → Project**

The objective is not only to learn how to write code, but also to understand:

* Why the code works
* How to structure programs
* How to translate business requirements into logic
* How to validate results
* How to progressively improve a solution
* How AI and ML systems evolve from simpler data-processing foundations

## Projects

### 01 — Customer Risk & Segmentation Engine

A rule-based Python application that processes customer information and applies business rules to determine:

* Customer segment
* Risk level
* Eligibility status
* Portfolio-level summaries

This project begins as a Python rule-based engine and will progressively evolve as new concepts are learned.

Planned evolution:

**V1 — Python Rule-Based Engine**
Business rules, functions, loops, dictionaries, and portfolio summaries.

**V2 — Data Processing with Pandas**
Load and process customer information from external datasets.

**V3 — Data Validation & Error Handling**
Improve reliability by validating inputs and handling unexpected data.

**V4 — Exploratory Data Analysis**
Analyze customer characteristics, distributions, and risk patterns.

**V5 — Machine Learning**
Replace or complement predefined rules with predictive models.

**V6 — API Deployment**
Expose predictions through an API for integration with other applications.
